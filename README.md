# Cutest Cat — make.fun entry (cutest-cat-01)

A front-facing ginger kitten, drawn procedurally in `main.ts` (Node 22,
standard library only). No image files, no network, no randomness: the
program rasterizes the cat from fixed constants at 2x supersampling and
writes a hand-encoded PNG to `/output/entry.png`, byte-identical on every
run.

The kitten: oversized round head with a slight tilt, huge sparkling amber
eyes, pink inner ears, a "w" smile, blush and whiskers, a cream belly,
one oversized clumsy paw raised toward the viewer (with toe beans), a
curled striped tail, and a pink yarn ball with a loose strand.

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
